\# Visitor Pass Management System



A MERN Stack based Visitor Pass Management System for managing visitors in an organization.



\## Features



\- Admin Login

\- Visitor Registration

\- Visitor Management Dashboard

\- Approve / Reject Visitors

\- Visitor Entry Time

\- Visitor Check-Out

\- QR Code Visitor Pass

\- Print Visitor Pass

\- Search Visitors

\- MongoDB Database



\## Technologies Used



\- React.js

\- Vite

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- JavaScript

\- CSS

\- QR Code
